# Sharjah Car Recovery

A Next.js website for Sharjah Car Recovery — 24/7 car recovery, towing, roadside assistance, breakdown recovery,
jumpstart and flatbed recovery services across Sharjah, UAE.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Structure

- `app/` — Next.js App Router pages (home, services, about, contact, areas)
- `components/` — Reusable UI and page-section components
- `lib/site-config.ts` — Central business details, service list and coverage areas
